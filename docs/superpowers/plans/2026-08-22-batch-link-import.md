# 批量链接导入实施计划

1. 用测试定义批量文本解析、规范化去重、无效项和容量限制。
2. 增加批量领域对象、解析器与 TXT 安全读取。
3. 用测试定义多链接扫描、批内/全局重复统计和单任务预览。
4. 扩展任务来源类型和 `TaskPlanner`，保持单事务提交语义。
5. 用 Qt 测试定义多行窗口、TXT 拖入、失败保留与进度交互。
6. 实现批量窗口和主窗口入口。
7. 用控制器测试定义预检、一次确认、提交、取消和错误恢复。
8. 接入应用信号与批量确认摘要。
9. 增加端到端测试：多来源、无效/重复输入、既有媒体、一次任务入队和重启读取。
10. 运行批量功能聚焦测试、全套回归和静态检查，形成第 6 项候选提交。
