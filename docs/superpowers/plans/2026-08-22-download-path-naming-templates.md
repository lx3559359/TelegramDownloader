# 下载目录与命名模板实施计划

1. 用测试定义模板语法、默认兼容、全部占位符和路径穿越防护。
2. 在文件路径层实现不可变命名设置、验证器和统一目标渲染器。
3. 扩展 `AppSettings` 与兼容加载，覆盖旧 JSON、损坏配置和原子保存。
4. 用 Planner 测试覆盖普通链接、搜索、订阅和批量任务的模板路径。
5. 向 `TaskPlanner` 注入并支持运行时更新命名设置。
6. 用 Qt 测试定义下载路径标签页、预设、实时预览、错误保留和往返值。
7. 实现设置界面，并在应用装配与控制器保存成功后即时配置 Planner。
8. 改为根据持久化媒体目标打开任务实际目录，覆盖单来源和跨来源。
9. 增加端到端重启测试：新模板持久化、新任务采用、旧任务不移动、目标不越界。
10. 运行路径、设置、Planner、控制器、UI 与打包聚焦回归，形成第 8 项候选提交。
