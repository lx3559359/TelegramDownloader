# 全局媒体调度实施计划

1. 用测试定义带任务键许可池的轮转、公平性、取消和动态缩放。
2. 扩展全局并发许可池，同时保持无键调用和异步上下文兼容。
3. 用调度器测试定义多活动任务、总媒体槽上限和等待队列优先级。
4. 将单活动操作改为受槽数约束的活动操作集合，并接入带任务键许可。
5. 覆盖多活动任务的暂停、下载时段关闭/恢复、关闭宽限和重复提交。
6. 更新调度快照、控制器摘要和任务队列位置。
7. 更新设置与主窗口文案为“全局媒体槽”，补 UI 测试。
8. 增加真实仓库端到端测试，验证多个任务、通知和重启状态。
9. 运行调度、资源控制、控制器和 UI 聚焦回归，形成第 7 项候选提交。
