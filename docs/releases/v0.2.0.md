# TelegramDownloader 0.2.0

本版本改进登录、私有链接下载可靠性和故障诊断，继续同时提供绿色便携包与非 C 盘安装包。

- 首次配置个人 API ID/API Hash 后，默认使用 Telegram App 扫码登录。
- 二维码完全在本机内存生成，支持过期自动刷新、手动刷新和两步验证。
- 保留手机号、验证码和两步验证备用登录流程。
- 修复 StringSession 重启后可能无法解析已加入私有 `t.me/c/...` 频道或群组的问题。
- 扫描错误改为持续显示，任务表新增“错误”列并保留失败原因。
- 消费后台任务异常，避免 asyncio 把第三方原始异常和潜在秘密写入日志。
- 日志新增 QR token 脱敏；`--self-test` 会验证 qrcode 等冻结运行时组件且不输出账号数据。
- API Hash、代理密码和现有 StringSession 的 DPAPI 存储格式不变，升级后无需迁移或重新输入有效会话。
- 所有应用数据、日志、更新缓存和下载内容继续保存在应用/项目目录，不持久占用 C 盘。
