# TelegramDownloader v0.7.0

## 下载任务管理中心

- 任务支持按名称搜索，并按全部、进行中、已暂停、部分失败、已完成和已归档筛选。
- 任务表支持多选，可批量暂停、继续和重试失败任务；重复点击不会启动第二批相同操作。
- 单选任务后展示媒体文件、类型、状态、进度、大小、重试次数和安全错误，已完成文件支持双击打开。
- 已完成任务可以安全归档和恢复；归档不会删除下载文件、媒体记录或去重依据。

## 性能与安全

- 任务摘要改为一次 SQLite 聚合查询，消除实时刷新时的逐任务 N+1 查询。
- 只有单选任务读取媒体明细，多选时保持轻量批量操作提示。
- 打开文件前重新读取媒体记录、检查完成状态、验证文件存在并通过应用目录路径守卫。
- 旧任务数据库自动增加可空归档字段，迁移幂等且保留全部原任务和媒体记录。
- 配置、加密会话、数据库、日志、缓存、临时文件、更新数据和下载内容继续全部位于应用目录。
