# TelegramDownloader v0.12.2

## 下载响应与磁盘效率

- 下载分片改为后台批量写盘，减少高频小块写入和刷新带来的磁盘开销；网络接收、界面操作与文件写入可以更顺畅地并行。
- 进度只统计已经确认写入 `.part` 文件的字节；暂停、取消和完成仍执行持久化提交，并保持断点续传、最终大小与 SHA-256 校验语义不变。
- 大文件和多任务压力场景增加事件循环心跳、最终文件、分片清理与哈希一致性回归。

## 渐进搜索

- Telegram 直接命中的媒体会先渐进显示，不再等待相册扩展和所有缩略图完成后才出现结果；结果稳定前仍禁止加入下载队列。
- 每页结果、游标和完成状态在同一 SQLite 事务中提交；临时结果与稳定结果使用一致 ID，页面通过增量插入、更新和删除保持选择与滚动状态。
- 相同缩略图的并发请求会合并，失败请求进入短暂冷却；`v0.12.1` 的 FloodWait 倒计时、同游标重试和未完成搜索恢复能力继续保留。

## 异步工具交互

- 暂停、继续、重试、优先、归档和恢复任务改为批量读取、批量写入和单次刷新，减少大任务列表下的数据库往返。
- 搜索、加载更多使用“最新操作替换旧操作”策略；保存设置、诊断、登录和其他不可重入操作自动去重，避免重复点击创建并发冲突。
- 内容历史、缩略图缓存、诊断、设置和订阅等文件或数据库操作移至工作线程；任务和订阅列表在行顺序不变时增量更新，不再重置整个模型。

## 兼容性

- 本版本是 `v0.12.1` 的性能与响应性补丁，数据库 schema 仍为 4，在线更新协议、应用目录、任务、下载文件、订阅、设置、DPAPI 凭据和有效登录会话保持兼容。
- 在线更新继续使用 GitHub / 魔搭双源、Ed25519 签名清单与资产 SHA-256 校验。
