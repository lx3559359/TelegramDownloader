# TelegramDownloader v0.3.1

正式版同步发布到 GitHub 与魔塔，并通过双源签名清单提供在线更新。

## 修复内容

- 修复 Telegram 已保存会话被服务端撤销后，账号内容页可能长时间停留在“正在同步”或搜索显示 `AuthKeyUnregisteredError` 的问题。
- 将授权密钥失效、重复使用和会话撤销统一转换为安全、可读的“Telegram 登录已失效，请重新扫码登录”提示。
- 会话失效时立即结束同步与搜索忙碌状态，保留群组缓存、搜索历史、下载任务和已下载文件。
- 只从项目内加密凭据中删除已经失效的 `session`；API ID、API Hash、代理配置和其他项目内数据保持不变。
- 自动断开旧连接，以空会话重建 Telegram 网关并打开二维码登录窗口，无需重新获取 API ID/API Hash。

## 数据与兼容性

- 继续支持 Windows 10/11 x64、便携包和当前用户安装包。
- 配置、加密会话、数据库、日志、缓存、更新文件与下载内容仍全部位于应用目录，不持久占用 C 盘。
- 原位升级和普通卸载继续保留 `data` 与 `downloads`；发布包不包含真实用户数据或 Telegram 凭据。

## 发布验证

```powershell
$env:QT_QPA_PLATFORM='offscreen'
.\scripts\test.ps1
.\scripts\build.ps1
.\scripts\build-installer.ps1 -SkipAppBuild
```

以上流程验证网关异常映射、同步与搜索恢复、完整 Python 测试、Ruff、便携包自检、用户数据排除，以及安装器升级/卸载数据保持。
