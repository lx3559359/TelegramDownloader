# TelegramDownloader v0.12.1

## 搜索限流恢复

- Telegram 搜索遇到不超过 120 秒的限流等待时，界面显示逐秒倒计时，并使用原分页游标自动重试；单次搜索操作最多重试 2 次。
- 倒计时期间可以取消搜索，取消后不会继续发出重试请求，当前搜索记录会标记为可恢复的未完成状态。
- 等待超过 120 秒或连续重试次数用尽时，不再把已有结果判定为失败或丢弃；页面保留结果、分页游标和脱敏错误，并提供“继续搜索”。
- 运行日志只记录等待秒数、重试次数和数值游标，不记录搜索词、账号、群组名称或消息内容。

## 500 条结果与全账号搜索

- 500 条结果通过多个 Telegram 分页逐步获取，不依赖单次请求返回全部内容；短限流恢复后继续使用同一游标，不会跳页或重复保存结果。
- 单会话搜索和 v0.12.0 新增的全账号搜索共用限流恢复机制；全账号稀疏分页、真实来源、相册隔离和账号级总数量上限保持不变。
- 自动等待只处理 Telegram 明确返回的短期限流；网络断开、账号授权失效和其他错误继续进入各自既有的重连或重新登录流程。

## 兼容性

- 本版本是 v0.12.0 的搜索可靠性补丁，不改变数据库 schema、任务、下载文件、订阅、设置、DPAPI 凭据或有效登录会话。
- 在线更新继续使用 GitHub / 魔搭双源、Ed25519 签名清单与资产 SHA-256 校验。
