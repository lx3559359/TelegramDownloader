# TG 快取 v0.18.3

## 下载响应速度

- 下载进度数据库写入移到后台命令通道，人工慢磁盘操作不再直接阻塞窗口事件循环。
- 同一媒体在固定 500 ms 窗口内只保留最新进度，并把多个媒体的批量进度合并为一次 SQLite 事务，减少高频小写入。
- 暂停、失败、重试和完成会先刷新对应媒体的待处理进度并完成耐久提交，旧进度不能越过终态。
- 调度器的任务读取、状态切换、优先级和恢复操作使用同一有序持久化边界；应用退出会先排空并关闭协调器，再断开 Telegram 连接。
- 强制终止进程最多可能损失不足 500 ms 的数据库显示进度；实际续传仍以同目录 `.part` 文件长度为准。

## 兼容性与隐私边界

- 不需要数据库迁移，不改变已有任务、下载目录、命名模板、账号会话或用户配置；升级后可直接继续现有任务。
- 不增加系统权限、后台服务或新的联网行为。
- 响应基准只使用临时目录、固定合成字节和人工慢仓库，不读取真实数据库、账号、消息、文件名、下载路径或凭据，也不连接 Telegram。

## 发布边界

- 当前说明对应本地候选版本；只有在用户另行明确授权正式发布后，才会创建标签、上传制品并推进在线更新指针。
