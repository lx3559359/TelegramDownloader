# TelegramDownloader v0.11.1

## 授权失效统一恢复

- 自动订阅在后台检查中发现 Telegram 授权失效后，会先把规则标记为“需要重新登录”，随后立即进入与前台一致的重新登录流程。
- 同一时间出现多个授权失效事件时只执行一次会话清理和登录窗口唤起，避免重复断开连接或连续弹出二维码页。
- 新登录成功后会恢复正常监测，后续授权失效仍可再次触发完整恢复流程。

## 更准确的连接状态

- “连接正常”现在同时要求 Telegram 网络连接可用且当前账号授权有效，不再只依据底层 socket 连接状态判断。
- 授权检查遇到临时网络故障时保留已保存会话，并提示检查网络或代理后重试，不会误删登录状态。

## 脱敏诊断

- 授权异常按固定类型记录，包括授权密钥重复、无效、未注册、会话撤销、未授权和未知类型。
- 日志与健康诊断只保存固定原因码，不写入 Telegram 返回的原始异常文本、会话内容或账号信息。

## 兼容性

- 本版本是 v0.11.0 的补丁更新，不改变任务数据库、内容数据库或设置格式。
- 既有任务、搜索记录、订阅、下载文件、DPAPI 凭据和有效登录会话均原位保留。
- 在线更新继续使用 GitHub / 魔搭双源、Ed25519 签名清单和资产 SHA-256 校验。
