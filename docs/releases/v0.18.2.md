# TG 快取 v0.18.2

## 响应速度

- 搜索结果模型改为线性更新，并使用结果 ID 索引定位行与缩略图；10,000 条合成结果的首次装载和单行更新均纳入固定基准。
- 渐进式搜索结果按短周期合并刷新，首批、搜索条件变化和最终稳定快照仍会立即显示，同时保留滚动锚点。
- 搜索目录查询、历史加载、选择保存和入队预检迁移到后台 SQLite 工作线程，避免阻塞窗口事件循环。
- 缩略图加载前的目录查询也迁移到后台工作线程，避免磁盘繁忙时拖慢搜索结果交互。
- 单项选择使用合并写入，全选和反选使用选择批处理与单事务提交；连续切换历史记录采用 latest-wins，只展示最后一次请求。
- 入队流程拆分为后台预检、快速提交和后台校正；入队幂等恢复可在后处理失败后根据已有任务修复目录状态。

## 兼容性与隐私边界

- 搜索语义、下载任务格式、数据库结构、设置、现有账号会话和二维码登录流程保持兼容性。
- 性能基准只创建固定合成结果，不读取真实数据库、账号会话、消息、关键词、下载路径或 Telegram 链接。
- 验证记录只保留测试数量、耗时、性能比例、构建产物大小和校验值，不记录用户内容。

## 发布说明

- 本版本已完成本地候选验证，并在用户明确授权后进入正式发布事务；在线更新清单、公开安装包和版本标签由该事务逐项校验后统一更新。
