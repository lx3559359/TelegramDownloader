# TelegramDownloader v0.3.0 候选说明

状态：本地候选版本，尚未创建 GitHub Release、魔搭版本或远端 stable 指针。

## 新功能

- 新增“账号内容”页面，自动列出当前账号已经加入的群组与频道，并区分归档和不可用状态。
- 支持必填关键词、日期、六种媒体类型及最多 10,000 项的 Telegram 服务端分页搜索。
- 支持相册完整补齐、逐项选择、全选/反选、加载更多，以及分页和相册交叉结果去重。
- 新增账号隔离的搜索历史、选择状态和缩略图缓存；离线启动仍可查看已有记录。
- 搜索结果可复用现有下载队列、断点续传和目录归档，并在预览与提交两个阶段执行数据库级去重。
- 设置页可单独清理缩略图缓存，不影响搜索记录、下载任务或已下载文件。

## 兼容性与数据迁移

- 继续支持 Windows 10/11 x64、便携包和当前用户安装包。
- 旧版任务数据库首次打开时会幂等增加可选显示标题字段，已有任务和下载路径不变。
- 新的内容目录使用独立的 data/database/catalog.sqlite3；缩略图位于 data/cache/thumbnails。
- 配置、加密会话、数据库、缓存、临时文件和下载内容仍全部位于应用目录。
- 原位升级和普通卸载保留 data 与 downloads；便携 ZIP 和安装源不包含真实用户数据。

## 已知边界

- 只显示当前 Telegram 账号已经加入且有权访问的群组和频道，不自动加入会话或绕过平台权限。
- 搜索关键词不能为空；每次网关请求最多检查 100 条消息，更多结果需继续加载。
- 相册不会为满足数量上限而拆分；剩余容量不足时整组延后，达到总上限时整组跳过并显示说明。
- 离线状态只能查看本地缓存，不能同步、搜索或把新选择加入下载队列。
- 缩略图加载失败只显示媒体类型图标，不影响文本结果和下载任务。
