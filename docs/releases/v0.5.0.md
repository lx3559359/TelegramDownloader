# TelegramDownloader v0.5.0

## 自动订阅下载

- 新增“自动订阅”工作区，可为当前账号已加入的群组或频道创建关键词媒体订阅。
- 支持图片、视频、音频、语音、文档和压缩包筛选，以及 5、15、30、60、180 分钟检查间隔。
- 新规则先建立最新消息基线，默认只处理启用后的新消息，不会意外下载全部历史。
- 每次最多检查 500 条新消息；存在积压时保存安全游标，短暂让出前台后继续。
- 规则支持立即检查、暂停、继续、编辑和删除；删除规则保留已有任务和文件。
- 增量读取使用单调消息游标和数据库去重，相册会完整展开，匹配项复用现有可恢复下载队列。

## 可靠性与反馈

- 自动检查与前台登录、群组同步和搜索协调，前台操作优先，后台规则串行执行。
- 网络失败采用渐进退避，FloodWait 按 Telegram 要求等待；登录失效和访问受限会显示明确状态。
- 首次基线失败、异常退出和中断检查均可恢复，不会永久停留在“处理中”。
- 页面显示检查进度、规则状态、下次运行时间，以及最近一次扫描、匹配、新增和重复统计。
- 订阅规则、游标和运行历史保存在应用目录的 `data/database/catalog.sqlite3`；不使用 Windows 服务或计划任务。
