# TG 快取 v0.17.0

## 更安全的账号入口

- 点击侧栏“账号”现在只打开账号状态页面，不会自动生成二维码，也不会断开当前 Telegram 会话。
- “重新登录 / 切换账号”需要明确确认，并使用独立候选会话完成授权；新会话确认成功前，当前账号、搜索、订阅和下载服务保持不变。
- 切换不同账号时会进行第二次确认；存在活动下载时会阻止切换，提交失败会回滚到原账号和原加密会话。

## 真正的手动更新

- 设置新增“关于与更新”页面，集中显示当前版本、正式通道、上次成功检查时间和“检查更新”按钮。
- 启动时不会自动检查更新；只有用户点击按钮后才访问签名更新源，发现新版本后仍需明确确认才会下载和安装。
- 检查中、最新版本、暂不可用和检查失败均提供明确状态，不会把失败记录为成功检查。

## 搜索与界面体验

- 搜索摘要恢复为稳定的单行省略显示，悬停可查看完整内容；大量结果滚动时不再因文字重排改变行高。
- 设置窗口完整显示“常规、下载路径、后台与通知、关于与更新”四个标签，无需左右滚动查找更新入口。
- 托盘菜单、复选框和文件夹选择器继续沿用上一版本的可读性与路径安全改进。

## TG 快取品牌

- 用户可见产品名称统一为“TG 快取 · 媒体下载器”，并启用体现 Telegram 媒体收集与下载的新图标。
- 主窗口、启动画面、设置、登录、更新提示、托盘、EXE、安装器、开始菜单和桌面快捷方式均使用新品牌。
- 升级安装会删除旧快捷方式并创建“TG 快取”快捷方式；`TelegramDownloader.exe`、安装目录、AppId、配置、数据库、加密会话和下载文件保持兼容。
