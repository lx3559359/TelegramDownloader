# TelegramDownloader v0.4.0

## 会话稳定性

- 增加 Windows 单实例保护，重复启动只显示提示，不再并行占用同一 Telegram 会话。
- 启动时先展示本地缓存的群组与搜索历史，再在后台恢复已保存会话，正常情况下无需重复扫描二维码。
- 增加周期连接监测和有上限的自动重连；短时断网不会删除会话，重连失败时可手动重试。
- 修复本次运行刚完成扫码或手机登录后未启动连接监测的问题。

## 内容浏览与预览

- 群组刷新增加“刷新中”状态、不确定进度条、实时发现数量和最终总数，并防止重复刷新任务。
- 搜索增加即时进度条、已扫描数量、匹配数量和处理阶段；支持取消当前搜索，并自动停止被新搜索替换的旧任务。
- 搜索结果缩略图扩大到 112×84，双击预览列可在应用内打开大图，支持适应窗口和原始尺寸切换。
- 预览加载失败只显示安全错误，不影响当前搜索结果和选择状态。

## 性能优化

- 缓存 Telegram 实体解析结果，减少群组同步、搜索和预览中的重复网络请求。
- 相册展开和缩略图加载采用上限为 4 的有界并发，同时保持搜索结果顺序稳定。
- 仅为当前可见结果行请求缩略图，降低大量结果下的网络和界面负担。

## 安装与数据

- 修复项目路径包含空格时 Inno Setup 参数被拆分、安装包无法生成的问题。
- 继续提供 Windows 10/11 x64 便携包和安装包，并保留签名在线更新能力。
- 设置、DPAPI 加密凭据、数据库、日志、缓存、临时文件、下载内容和更新文件继续保存在程序所在目录，不写入 C 盘用户数据目录。
- 覆盖升级与普通卸载继续保留 `data` 和 `downloads`。

## 验证

- 完整 pytest 与 Ruff 检查通过。
- 便携版路径自检、更新健康检查以及安装版安装、覆盖升级、卸载和数据保留冒烟测试通过。
- Windows 图形界面已验证直接启动、单实例提示和账号内容页面布局。
