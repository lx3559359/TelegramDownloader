# TelegramDownloader v0.11.2

## 搜索结果勾选修复

- 修复账号内容搜索结果首列只能高亮行、无法真正勾选的问题；Qt 委托传入的整数状态现在会被正确规范化。
- 鼠标点击整个“选择”单元格都可以切换勾选，不必精确点中小方框；聚焦首列后按空格键也可以切换。
- 不可用或已经加入下载队列的结果仍保持不可勾选，每次交互只产生一次状态更新。

## W3 白色卡片布局

- 账号内容页改为浅灰蓝画布和三张白色卡片，卡片使用渐变、高光与真实投影强化立体层级。
- 群组列表、筛选区和结果区重新分层；日期、数量和媒体类型不再争抢同一行空间。
- 选择、预览、日期、类型、大小和状态采用固定列宽，摘要获得剩余空间并只在自身列内省略；悬停可查看完整摘要。
- 长群组名称使用右侧省略，不再出现水平滚动条或文字越界。

## 兼容性

- 本版本是 v0.11.1 的界面与交互补丁，不改变 Telegram 搜索、预览、队列、数据库或下载协议。
- 既有任务、搜索记录、订阅、下载文件、设置、DPAPI 凭据和有效登录会话均原位保留。
- 其他导航页面继续使用原有深色主题；在线更新继续使用 GitHub / 魔搭双源、Ed25519 签名清单和资产 SHA-256 校验。
