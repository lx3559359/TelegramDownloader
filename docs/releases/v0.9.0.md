# TelegramDownloader v0.9.0

## 文件完整性

- 全新下载、断点续传和已存在完成文件都会记录完整内容的 SHA-256 与 UTC 校验时间。
- 旧版完成记录无损迁移为“未校验”，首次手动校验建立本地基线；启动时不会自动扫描全部文件。
- 校验结果可区分文件缺失、大小异常、同尺寸哈希异常和无法读取，并提供可取消进度反馈。

## 精准修复

- 任务详情支持媒体多选、“校验所选”和“重新下载所选”；任务表支持批量“校验文件”。
- 只重新下载确认异常的媒体，不会顺带重试同任务下其他失败项。
- 现有最终文件与 `.part` 分片先移动为冲突安全的 `.corrupt*` 留档，不静默覆盖或删除。

## 数据与兼容性

- v0.8.0 的任务、搜索、订阅、登录会话和下载目录原位保留，数据库迁移可重复执行。
- SHA-256、校验状态、留档、临时文件和下载内容全部保存在应用目录，不持久写入 C 盘业务目录。
- 在线更新继续使用 GitHub / 魔搭双源、Ed25519 签名清单和资产 SHA-256 校验。
