# TG 快取 v0.18.0

## 首次登录 API 指南

- 首次登录且尚未填写完整 API 凭据时，登录窗口默认展开五步指南；已有完整凭据时默认折叠，之后仍可随时重新展开。
- 指南从准备 Telegram 账号开始，说明国际格式手机号、Telegram 消息中的确认码、**API development tools** 入口，以及创建个人应用时可参考的字段示例。
- 官方申请入口固定为 [my.telegram.org/apps](https://my.telegram.org/apps)，点击后只通过系统默认浏览器打开。

## 更明确的安全与失败回退

- 本程序不内嵌 Telegram 网页，也不会读取用户在官网输入的手机号或确认码。
- 系统浏览器无法打开时会显示可选择、可复制的官方网址；复制失败时仍保留手动选择网址的方式。
- 指南明确提示每个手机号只能关联一个 API ID，API Hash 与密码类似，不应截图、分享或提交到公开网站，并提醒遵守 Telegram API 条款。

## 登录窗口体验与兼容性

- 凭据页改为仅纵向滚动，在 100% 与 125% 显示缩放下不会出现横向滚动，API、代理和提交按钮都可到达。
- 指南的展开、折叠和网址操作不会修改已输入内容；按回车仍会提交 API 凭据，不会误触发指南按钮。
- 现有代理配置、二维码登录、手机号验证码、两步验证、加密会话恢复和账号安全切换流程保持兼容。
