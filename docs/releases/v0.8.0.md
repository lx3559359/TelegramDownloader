# TelegramDownloader v0.8.0

## 启动与下载可靠性

- 启动加载阶段立即显示状态，主窗口不再等待账号与任务恢复完成后才出现。
- 普通链接、相册、搜索和订阅统一按 Telegram 媒体键去重，确认下载后发生并发变化也不会重复入队。
- 普通链接会明确报告实际加入与跳过重复的数量。
- 下载状态更新只读取目标媒体项，较大队列下减少不必要的数据库扫描。

## 首次公开的累计功能

- 自动订阅新媒体，并提供运行历史、原因诊断和不改变订阅状态的只读测试。
- 浏览账号已经加入的群组与频道，支持服务端关键词搜索、较大预览和选择性加入队列。
- 任务筛选、多选操作、媒体明细、文件打开和不删除文件的可恢复归档。

## 数据安全

- 配置、加密会话、数据库、日志、缓存、临时文件、更新数据和下载内容继续全部位于应用目录。
- 安装包继续拒绝安装到 C 盘；便携版与直启版不依赖用户目录保存业务数据。
- 重新打包只清理本次构建拥有的输出，不再删除 `dist/release` 下既有的版本化直启目录及其用户数据。
- 在线更新继续使用 GitHub / 魔搭双源、Ed25519 清单签名和 SHA-256 资产校验。
