# TelegramDownloader v0.3.2

本版本当前为本地候选版。GitHub、魔塔和在线更新签名清单将在用户确认候选版后发布。

## 修复与优化

- Telegram 短时断网后自动执行有上限的连接恢复，避免账号内容页一直停留在“同步中”或“等待中”。
- 进入账号内容页或选择群组时检查连接；群组列表缓存超过 60 秒才自动同步，手动刷新始终强制同步。
- 选择群组或频道后恢复该来源最近一次搜索的关键词、日期、媒体筛选和已有结果，不会自动扫描全部历史。
- 离线状态仍可编辑搜索条件；提交时先重连，失败后保留旧群组、旧结果和全部输入。
- 账号内容搜索框识别 `t.me` 链接，规范化后切换到任务中心并打开扫描预览；仍需用户确认后才能加入下载队列。
- 登录窗口回填已保存的 API ID、遮罩 API Hash 和代理设置，二维码网络失败不再表现为凭据丢失。
- 会话失效继续只删除无效 `session`，保留 API、代理、群组缓存、搜索历史、任务和下载文件。

## 数据与兼容性

- 继续支持 Windows 10/11 x64、便携包和当前用户安装包。
- 配置、加密凭据、数据库、日志、缓存、临时文件、更新文件与下载内容仍位于项目或应用目录。
- 测试和构建过程使用项目内 `.build-temp`、`.tool-cache` 和工作树，不新增 AppData 等 C 盘持久应用数据。
- 原位升级和普通卸载继续保留 `data` 与 `downloads`，发布包不包含真实用户数据或 Telegram 凭据。

## 候选版验证

候选版交付前执行完整 pytest 与 Ruff、便携包自检、安装包安装/卸载冒烟测试，以及 Windows 图形界面检查。实际通过数量、包大小和 SHA-256 将记录在 `docs/verification/2026-08-14-v0.3.2-checklist.md`。
