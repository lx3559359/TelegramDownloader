# TelegramDownloader v0.4.2

## 真实使用稳定性与交互优化

- 修复账号内容页、群组刷新、Telegram 重连和登录二维码操作点击后可能无响应的问题。
- 同一刷新、重连或登录切换运行期间不再重复启动，关闭程序时会安全取消未完成的界面动作。
- 重连、二维码刷新、手机号切换、凭据编辑和加入下载队列现在会立即显示进行中状态，并在成功、失败或取消后恢复。
- 保留搜索进度、缓存群组、搜索历史、双击预览和选择性下载能力；所有业务数据仍保存在应用目录。
- 关闭程序时为正在进行的 Telegram 传输保留最多 30 秒的收尾时间，避免暂停或退出期间强制取消连接协程。
- 搜索结果会明确显示已入队和不可用数量；没有可加入项目时自动禁用“全选”和“反选”。
- 任务操作按钮按状态启用：排队/下载/重试等待可暂停，暂停可继续，部分失败可重试，避免无效点击没有反馈。
- 在线更新允许 GitHub 和魔塔返回已签名但较旧的稳定版，并将其正确识别为“当前已是新版本”，不再误报更新源无效。

## 三轮真实化回归

- 连续三轮使用项目内真实会话验证群组刷新、搜索进度、双击预览、已入队反馈、真实下载、暂停续传和受控崩溃恢复。
- 三轮均验证 GitHub/魔塔签名更新源以及安装、覆盖升级、卸载数据保留；最终便携 ZIP 不包含本地会话或下载内容。
- 最终构建前后项目运行数据逐文件哈希一致；完整自动化、Ruff、便携版自检和安装器自检均通过。
