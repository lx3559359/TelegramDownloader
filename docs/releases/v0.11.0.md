# TelegramDownloader v0.11.0

## 可预测的统一下载队列

- 普通链接、账号内容搜索和自动订阅共用同一个任务队列，同一时刻只执行一个下载任务，避免大型任务互相争抢连接和磁盘。
- 等待任务直接显示队列位置；选中等待项可点击“优先下载”，任务会移动到当前活动任务之后，不会抢占或中断正在下载的任务。
- 队列按稳定的先进先出顺序运行，优先级写入本地 SQLite；异常退出或重启后仍按已保存顺序恢复。
- 暂停尚未开始的等待任务不会触碰媒体文件，关闭程序时会安全收敛活动任务并保留 `.part` 分片。

## 实时资源控制

- 设置页新增“总下载限速”，提供不限速、256 KiB/s、1 MiB/s、2 MiB/s、5 MiB/s 和 10 MiB/s 选项。
- “文件并发”明确控制单个活动任务内部的媒体并发数，支持 1–5；总下载限速由全部并发文件共享，不会按文件重复计算带宽。
- 并发与限速保存后立即应用，无需重启程序或重新登录；任务中心持续显示活动数、等待数、文件并发和当前限速。
- 等待中的任务不再各自高频查询数据库，任务较多时界面刷新和磁盘访问更平稳。

## 兼容性与数据边界

- 从 v0.10.0 升级只为任务表增加带默认值的 `queue_priority` 字段；既有设置、DPAPI 凭据、登录会话、任务、搜索、订阅、完整性记录、下载文件及 `.part` 分片均原位保留。
- 旧版设置文件自动采用“不限速”，原有并发值和其他字段含义不变。
- 继续交付 Windows 直启目录、便携 ZIP 和安装包；应用管理的全部业务数据仍保存在所选 D/F 等非 C 盘应用目录。
- 在线更新继续使用 GitHub / 魔搭双源、Ed25519 签名清单和资产 SHA-256 校验。
