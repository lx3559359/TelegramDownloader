# TelegramDownloader v0.16.0

## 自定义媒体下载目录

- 设置页新增只读下载根目录和 Windows 文件夹选择器，无需手动输入路径，并可一键恢复应用内默认目录。
- 新任务使用当前选择的目录；已有任务保持原路径，不会被移动或改名，并可继续从默认目录或历史受信目录续传、校验和维护。
- 外部磁盘、移动设备或共享目录不可用时会明确报错，不会静默回退到其他目录。

## 手动更新与界面可读性

- 启动时不再自动检查更新；只有点击设置页“检查更新”后才访问正式更新源，下载和安装仍需用户明确确认。
- 设置页、搜索页和表格复选框统一显示清晰白色勾号，并完善未选中、选中、焦点和禁用状态。
- 托盘右键菜单使用独立浅色主题，在 Windows 深色调色板下仍保持普通、选中和禁用文字可读。

## 搜索结果完整显示

- 搜索摘要取消省略号并完整自动换行，超出视口的长摘要可用像素级纵向滚动查看到结尾。
- 行高只对当前可见结果按需测量，并缓存列宽、字体和文本对应的结果，避免大量搜索结果初始布局遍历全表。
- 字体、缩放、列宽和滚动变化会重新计算必要的可见行，同时保持表格无水平滚动条。

## 安全与兼容性

- 当前和历史媒体目录使用独立受信根策略；未知目录、磁盘根目录、应用数据目录和越界路径会被拒绝。
- 配置、数据库、日志、缓存和更新事务继续保存在应用目录；自定义媒体目录不会放宽应用内部数据的路径边界。
- 旧版“启动自动检查更新”设置会被安全忽略并在下次保存时移除，现有任务、搜索、订阅、命名模板和在线更新签名协议保持兼容。
