# TelegramDownloader v0.13.0

## 托盘后台与单实例唤回

- 主窗口默认关闭到托盘，下载和自动订阅在当前用户登录期间继续运行；托盘菜单提供显示、隐藏、暂停全部、继续下载、立即检查订阅、打开下载目录和彻底退出。
- 第二次启动会激活已经运行的窗口，不再只提示“程序已运行”。正式打包程序可由用户选择通过 `--background` 在登录 Windows 后静默进入托盘。
- Windows 注销、关机、在线更新和托盘“彻底退出”都会走完整安全关闭流程，不会被关闭到托盘逻辑拦截。

## 隐私安全的系统通知

- 新增下载完成、部分失败、磁盘空间不足、订阅命中、登录失效、下载时段切换和正式版更新通知。
- 五秒内同类事件自动聚合，下载终态去重；通知文案不包含账号、来源、消息、搜索词、文件名或路径。
- 系统通知或托盘不可用不会改变下载、订阅、更新检查或登录状态，只影响提示方式。

## 每周下载时段

- 可按周一至周日设置同日、全天和跨午夜下载窗口，使用 Windows 当前时区计算下一次边界。
- 时段关闭会安全暂停活动下载；时段重新开放后，只恢复因时段暂停的任务，用户手动暂停保持不变。
- 自动订阅仍可在窗口外发现并加入任务，媒体等待下一个允许下载的时段。

## 设置与兼容性

- 设置页拆分为“常规”和“后台与通知”，后台行为、通知、开机启动和下载时段保存后即时生效；注册表、设置文件或运行时应用失败时回滚到旧状态。
- 开机启动默认关闭，仅管理当前用户 Run 键中的 `TelegramDownloader` 值；源码开发模式不写启动项。
- 旧设置文件、任务数据库、登录会话、下载文件、订阅、在线更新协议和非 C 盘数据边界保持兼容。
