# TelegramDownloader v0.6.0

## 自动订阅诊断中心

- 选中自动订阅规则后，可查看完整规则摘要和最近 20 次运行记录。
- 运行结果会解释没有新增任务的具体原因：没有新消息、关键词未命中、媒体类型不符、全部重复，或实际新增与重复数量。
- 新增“测试最近 100 条”只读探测，复用正式自动检查的关键词、媒体类型、相册展开和媒体去重逻辑。
- 探测显示扫描、关键词命中和媒体匹配进度，支持取消，并在完成后展示最多 20 个媒体样本。
- 探测不会推进增量游标、创建下载任务、修改规则或写入运行历史；样本仅驻留内存。

## 数据与可靠性

- 内容目录数据库自动从 schema v2 升级到 v3，旧运行记录保持可读；正式检查新增持久化关键词命中计数。
- 前台探测期间后台订阅调度会主动让路；切换账号、重新登录、会话失效或关闭程序前会先取消并等待探测结束。
- 失败结论和日志不包含群组名、规则关键词、消息摘要、文件名或 Telegram 原始异常内容。
- 配置、加密会话、数据库、日志、缓存、临时文件、更新数据和下载内容继续全部位于应用目录。

## 交付边界

- 本地候选版继续同时生成绿色便携包和拒绝 C 盘安装的安装包，并保留 GitHub / 魔搭双源签名在线更新能力。
- 本文件只记录候选版本；线上 stable 指针、Git 标签和公开资产仅在独立发布流程完成全部验证后推进。
