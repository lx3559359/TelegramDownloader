# TG 快取 v0.19.0

本版本集中加固健康诊断、命令行自检和 Windows 冻结构建边界，让诊断结果更接近当前真实运行状态，同时保持严格脱敏。

## 命令行自检安全

- --self-test 不再恢复或改写下载任务、媒体、搜索和订阅的业务状态；它仍可初始化兼容数据库结构并写入自检报告。
- --self-test 与 --update-health-check 共用主程序的单实例保护。主程序运行时再次执行会返回非零，不访问业务数据库，也不弹出窗口。
- 正常 GUI 启动仍保留既有中断恢复流程，升级后下载和订阅恢复语义不变。

## WAL 与数据库语义

- 任务库和内容库使用 WAL-aware 只读事务，在同一快照内完成 quick_check、完整表列结构、外键和业务状态检查。
- 不完整结构、外键损坏、未知枚举值、过长或类型异常的持久化值都会返回固定异常结果，不再以“正常”掩盖语义损坏。
- 诊断不会执行 checkpoint、写事务或自动修复，也不会导出表名、记录标识和非法原值。

## 凭据与存储

- 凭据检查现在区分文件存在、可解密和 API 凭据完整配置；空 API ID 或空 API Hash 不再显示为可用。
- 存储检查覆盖应用目录及当前下载目录的安全边界、可写性和磁盘空间；同卷只查询一次，不同卷分别判断。
- 可用空间低于 1 GiB 提醒关注，低于 256 MiB 判为异常；结果不展示盘符或真实路径。

## 网络、取消与脱敏详情

- Telegram 与双更新源检查均有 20 秒总时限；Telegram 诊断直接检查当前网关，不会启动共享重连任务。
- 点击取消后立即显示“正在取消”，网络检查会取消，本地线程检查在当前项收敛后停止，已完成结果继续保留。
- 维护中心新增固定处理建议与安全指标详情；只展示白名单布尔值、数量、耗时、版本和容量，不展示账号、群组、消息、文件名、路径、搜索词、会话或密钥。

## Windows 构建稳定性

- PyInstaller 只在受控 PATH 中执行，避免外部软件目录中的不兼容 ICU DLL 被误收集；构建结束后会恢复调用进程原有 PATH。
- 受控 PATH 的成功、非零退出和异常恢复都有自动化合同覆盖。

## 兼容性

- 不增加业务数据库版本，不迁移或修改已有任务、媒体、搜索、订阅、账号会话和下载目录。
- 不增加系统权限、后台服务或启动时联网行为。
- 诊断只报告问题，不自动修复数据库、凭据、网络、路径或更新源。

## 隐私边界

- 自动化验证只使用临时目录、合成数据库、合成凭据和受控错误，不读取真实账号、会话、消息、文件名、下载路径或用户数据库。
- 诊断包继续采用固定文件集合、严格字段白名单和固定摘要；未知指标与异常文本不会进入导出内容。

## 发布说明

- 本版本已完成本地实现、独立代码审查和合并门禁，并在用户明确授权后进入正式双平台发布事务。
- GitHub Release、魔搭候选、签名更新清单和 stable 指针由发布脚本在回下载逐字节校验后统一提升。
