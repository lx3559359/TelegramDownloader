# TelegramDownloader v0.14.0

## 托盘后台、通知与下载时段

- 主窗口可关闭到系统托盘，下载和自动订阅在当前用户登录期间继续运行；托盘菜单可显示/隐藏窗口、暂停/继续下载、检查订阅、打开下载目录或彻底退出。
- 新增隐私安全的聚合系统通知、可选的当前用户开机启动，以及按星期配置的同日、全天和跨午夜下载时段。
- 第二次启动会激活已有实例；注销、关机、在线更新和托盘退出继续走幂等安全关闭流程。

## 高级订阅规则

- 每条规则支持最多 20 个包含词、任意命中（OR）或全部命中（AND），以及最多 20 个优先排除词。
- 历史补抓可选最近 1、3、7、30 天；补抓使用固定截止消息并按页持久推进，失败、取消或重启后不会跳过尚未处理的消息。
- 旧单关键词规则自动迁移到 schema 5，保留启停状态、消息游标、运行历史与统一媒体去重语义。

## 批量导入

- 可粘贴最多 100 条 `t.me` 链接，或选择、拖入 UTF-8/GB18030 TXT 文件；TXT 合计上限为 1 MiB。
- 批量预检统计无效链接、输入重复、跨链接媒体重复和任务库既有媒体；确认一次后把全部有效媒体原子加入一个任务。
- 预检失败会保留原输入，Telegram 登录失效继续进入统一重新登录流程。

## 全局媒体槽

- 原并发设置升级为跨任务共享的 1–5 个全局媒体槽；多个单文件任务可并行开始，大任务与新任务按媒体槽轮转。
- 所有任务继续共享同一总下载限速；动态升降媒体槽无需重启，也不会强制中断已经开始的媒体。
- 多活动任务的暂停、下载时段切换、优先级、重复提交、通知和安全关闭均使用统一调度状态。

## 下载路径与命名模板

- 设置页新增“下载路径”，可组合来源、年月、媒体类型、消息日期和消息 ID，并实时预览目录及文件名。
- 默认布局保持 `{source}/{year_month}/{media_type}/{original_name}`；模板保存后只影响新任务，既有任务和断点续传路径不移动。
- 绝对路径、父目录跳转、未知占位符、Windows 非法名称和过长结果会被拒绝或安全化，最终目标始终限制在项目 `downloads` 目录内。

## 兼容与安全

- 旧设置自动补入后台、时段和下载命名默认值；任务数据库、登录会话、下载文件、`.part` 分片、完整性记录和在线更新协议保持兼容。
- 应用业务数据继续只保存在所选的非 C 盘应用目录；开机启动仅管理当前用户 Run 键中的一个固定值，不新增 Windows 服务或计划任务。
- 系统通知和日志继续使用固定脱敏文案，不包含账号、来源、消息、搜索词、文件名、链接或绝对路径。
