# TelegramDownloader v0.10.0

## 图形化健康诊断

- 左侧新增“健康诊断”，一键检查运行路径、项目内写入、磁盘空间、运行组件、两个本地数据库、登录凭据、Telegram 会话及 GitHub/魔搭签名更新源。
- 检查过程提供逐项进度、耗时与固定状态说明，支持取消并保留已完成结果；重复点击不会启动并发诊断。
- 打开诊断页只读取项目内历史，不会自动联网；所有在线检查都必须由用户点击“开始自检”触发。

## 严格脱敏诊断包

- 最近结果原子保存到 `data/diagnostics/latest.json`，诊断 ZIP 也只写入应用目录。
- ZIP 固定只有 `diagnostic-report.json` 与 `diagnostic-summary.txt`，只允许固定字段、布尔值、计数和延迟。
- 导出前递归拒绝凭据、手机号、Telegram 链接、账号/群组/消息/文件标识、绝对路径、项目根路径及环境用户名；运行期新产生的会话凭据也会动态加入拒绝列表。
- SQLite 使用严格不可变只读连接，不创建 WAL/SHM 辅助文件，不修改任务、搜索、订阅或下载数据。

## 兼容性与更新

- v0.9.0 的设置、DPAPI 凭据、登录会话、任务数据库、内容数据库、下载文件和完整性记录全部原位保留。
- 继续交付 Windows 直启目录、便携 ZIP 和安装包；安装及应用业务数据仍必须位于 C 盘和 Windows 系统盘以外。
- 在线更新继续使用 GitHub / 魔搭双源、Ed25519 签名清单和资产 SHA-256 校验。
