# TelegramDownloader v0.12.0

## 全账号资源搜索

- “账号内容”默认选择“全部会话”，无需预先选择群组，即可搜索当前账号有权访问的群组、频道、私聊、机器人、收藏夹和已归档云端会话。
- 搜索结果展示真实来源和来源类型，并按一个账号级总数量上限分页；仍可切换到指定群组或频道执行原有单会话搜索。
- 支持搜索其他参与者发送且仍保存在 Telegram 云端、当前账号仍有权访问的匹配媒体；秘密聊天、已删除或无权访问的历史不在搜索范围内。
- 多个来源的选中结果会合并为一个下载任务，文件继续按各自真实来源目录归档；任务的“打开目录”会打开下载根目录。
- 全局搜索使用可恢复的复合分页游标，自动补齐稀疏页面、隔离不同会话中的相册，并防止停滞游标造成重复请求。

## 界面与诊断集成

- 全账号结果新增独立来源列，同时保留 v0.11.2 的整格勾选、稳定列宽、长摘要省略和白色立体卡片交互。
- 全局银色立体主题覆盖主窗口、任务中心、账号内容、自动订阅、健康诊断和各类对话框，顶层画布保持不透明并统一层级。
- 账号内容数据库升级到 schema 4；健康诊断同步识别当前 schema，并继续只输出结构、状态和数量等脱敏指标。

## 兼容性与隐私边界

- 既有单会话搜索、任务、搜索历史、订阅、完整性记录、下载文件、设置、DPAPI 凭据和有效登录会话均原位保留。
- 本地搜索目录只保存匹配媒体所需的元数据和消息摘要，不导出完整聊天记录，也不绕过 Telegram 的访问权限、内容保护或服务端频率限制。
- 在线更新继续使用 GitHub / 魔搭双源、Ed25519 签名清单与资产 SHA-256 校验。
