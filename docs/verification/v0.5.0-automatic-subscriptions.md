## 真实账号与界面检查

使用项目内已有 DPAPI 加密会话的隔离副本进行非破坏检查，没有读取、打印或提交 API Hash、Session、手机号、群组名或消息正文。

- 已保存会话直接恢复，未显示二维码或手机登录窗口。
- 同步得到 4 个当前账号可用会话；报告只记录数量。
- 使用随机唯一关键词创建临时规则，因此不会匹配真实内容或创建下载任务。
- 完成基线、暂停、暂停状态下编辑、继续、自动检查和手动立即检查。
- 第二次连接后游标保持一致，证明规则可跨重启恢复。
- Qt 主窗口实际切换到“自动订阅”页，规则表格、最近统计和下次检查时间可见；项目内截图人工检查未发现遮挡或失效按钮。
- 临时规则已删除；检查前后任务数均为 0，原会话、原任务和原下载未修改。
- 外部桌面捕获接口曾被 Windows 图形权限拒绝；源程序窗口实际创建成功，最终界面检查改用 Qt 自身抓图完成。

## 端到端与交互加固

- 隔离端到端探针验证：首次基线不建任务，两个匹配媒体合并成一个下载任务，下载调度完成，重启后游标不倒退，重复运行不建任务，全部路径位于探针根目录。
- 运行中重复点击“立即检查”不会再排入第二次相同执行。
- 自动检查开始后编辑、暂停、删除等冲突操作立即锁定，结束后恢复。
- 创建和编辑基线被计入前台 Telegram 操作，后台规则不会争抢连接。
- 实际断线重连后等待网络的规则立即恢复，不必等待下一轮退避。
- 编辑已暂停规则不会意外恢复订阅。

## 数据边界

- 订阅规则、游标和最近运行保存在 `<应用目录>/data/database/catalog.sqlite3`。
- 下载任务保存在 `<应用目录>/data/database/tasks.sqlite3`，媒体保存在 `<应用目录>/downloads`。
- 缓存、日志、临时文件、更新暂存和加密凭据均由 `PortablePaths` 限制在应用目录。
- 不使用 Windows 服务、计划任务、注册表、`%APPDATA%`、`%LOCALAPPDATA%` 或系统临时目录保存业务数据。

## 已知范围

- 自动检查只在主程序运行期间执行，不安装后台服务或计划任务。
- 一条规则支持一个关键词；复杂布尔条件通过后续版本设计。
- 单次最多读取 500 条新消息，积压会保存安全游标后继续。
- 本版不包含历史补抓、跨群组全局搜索、带宽限速或外部通知。
