## 外部依赖边界

自动化验收不读取或输入真实 Telegram 凭据，因此真实账号内容、服务端权限、FloodWait 和实际网络吞吐仍取决于用户账号与 Telegram。开机启动和通知使用可注入适配器完成无副作用测试，发布构建验证正式 Windows 组件可用；验收过程不会修改当前用户的真实开机启动设置，也不会产生包含账号、链接、关键词、文件名或路径的通知内容。
