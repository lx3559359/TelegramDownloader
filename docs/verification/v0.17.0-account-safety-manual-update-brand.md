## 功能验收

- 点击账号入口只打开账号状态页，不再自动生成二维码或破坏当前登录会话；重新登录和切换账号必须由用户明确触发与确认。
- 候选账号使用独立会话授权，成功提交前保留原账号；活动下载阻止切换，失败路径回滚原会话。

- 产品名称统一为“TG 快取 · 媒体下载器”，主窗口、托盘、EXE、安装器与快捷方式使用新的 TG 媒体下载图标；原程序文件名、AppId、配置、数据库、会话和下载文件保持兼容。
