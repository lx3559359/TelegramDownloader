## 真实账号与界面检查

使用项目内已有 DPAPI 加密会话的隔离副本进行非破坏验证，没有读取、打印或提交 API Hash、Session、手机号、群组名、规则关键词、消息摘要或文件名。

- 已保存会话直接恢复，未要求重新扫描二维码。
- 同一规则的重复探测请求被合并，不会并发执行两次。
- 取消操作立即可见，之后可重新开始并正常完成探测。
- 使用随机唯一关键词完成正式检查，没有创建下载任务；检查前后任务数量一致。
- 探测前后规则游标、规则内容、任务表和运行历史均保持不变。
- 正式检查产生的解释性历史跨程序重启后仍可读取。
- schema 自动升级为 3；隔离运行产生的配置、数据库、日志、缓存和临时数据全部位于项目内 QA 根目录。
- 1280×768 与 1024×720 两种窗口尺寸均完成实际 Qt 抓图检查；按钮、规则表、诊断摘要、历史表和样本表无重叠、裁切或隐藏操作，长文本按设计省略或换行。
- QA 脚本和抓图只保存在被忽略的项目临时目录，不进入提交或发布包。

## 数据边界

- 订阅规则、游标和最近运行记录保存在 `<应用目录>/data/database/catalog.sqlite3`。
- 下载任务保存在 `<应用目录>/data/database/tasks.sqlite3`，媒体保存在 `<应用目录>/downloads`。
- 设置、DPAPI 加密凭据、缓存、日志、临时文件、缩略图和更新暂存均由 `PortablePaths` 限制在应用目录。
- 只读探测样本仅驻留内存，不持久化 Telegram 内容。
- 不使用 Windows 服务、计划任务、注册表、`%APPDATA%`、`%LOCALAPPDATA%` 或系统临时目录保存业务数据。
