## 隔离与隐私边界

- 自动化没有读取或输入真实 Telegram 凭据，没有发起真实媒体下载，也没有修改真实媒体文件。
- 视觉验收使用生产 Qt 控件与临时合成数据；发布记录不包含账号、会话、消息、搜索词、文件名、下载路径、API ID、令牌或密钥。
- Ed25519 私钥和 ModelScope 令牌只从已忽略的项目本地秘密目录读取，没有输出到日志、提交或发布资产。
- 功能工作树共享虚拟环境曾把 editable 安装指向隔离工作树；发布前已按主项目路径重新安装并确认导入版本为 `0.16.0`。
