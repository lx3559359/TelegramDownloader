## 真实账号与界面检查

使用项目内已有 DPAPI 加密会话的隔离副本进行非破坏验证，没有读取、打印或提交 API Hash、Session、手机号、群组名、消息内容或真实文件名。

- 已保存会话直接恢复，没有请求二维码或重复登录。
- 六种筛选计数、标题关键字筛选、多行选择和批量动作均返回预期结果。
- 单任务媒体明细正确加载；已完成且存在的应用内文件可以打开。
- 文件缺失和应用目录外路径均被安全拒绝。
- 已完成任务可归档、可恢复；程序重启后归档状态仍保留。
- 归档和恢复前后媒体记录与去重证据保持不变。
- 迁移后任务表包含归档字段；隔离运行产生的设置、数据库、日志、缓存、临时文件和下载目录全部位于项目内 QA 根目录。
- 1280×780 与 1180×720 两种窗口尺寸均完成实际 Qt 抓图检查；搜索、筛选、任务表、明细表和批量操作无重叠、裁切或隐藏操作。
- 真实界面检查发现“明细已同步返回后又被加载提示覆盖”的同步信号竞态；已调整状态更新顺序并增加回归测试，复测后正确显示媒体文件数量。
- QA 脚本、会话副本和抓图只保存在被忽略的项目临时目录，不进入提交或发布包。

## 数据边界

- 下载任务和媒体记录保存在 `<应用目录>/data/database/tasks.sqlite3`，媒体文件保存在 `<应用目录>/downloads`。
- 归档仅写入任务的 `archived_at`；不删除媒体文件、媒体行或去重记录。
- 账号内容、订阅规则和游标保存在 `<应用目录>/data/database/catalog.sqlite3`。
- 设置、DPAPI 加密凭据、缓存、日志、临时文件、缩略图和更新暂存均由 `PortablePaths` 限制在应用目录。
- 不使用 Windows 服务、计划任务、注册表、`%APPDATA%`、`%LOCALAPPDATA%` 或系统临时目录保存业务数据。
