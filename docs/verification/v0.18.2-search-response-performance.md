## 实现级合同

- 事件循环心跳：搜索目录提交和入队预检分别注入最长 300 ms 的本地阻塞，异步心跳均连续推进 10 次，操作在释放前保持未完成。
- SQLite 边界：搜索快照使用一次原子读取；单项补丁、全选和反选各使用一次选择事务，不再按结果逐行开启事务；目录连接边界在并发线程中保持串行。
- Qt 信号范围：10,000 条结果建立稳定 ID 行索引时不重置模型；插入、删除、重排和连续变更使用范围信号，持久索引、缩略图和当前行按稳定 ID 保留。
- 代次与并发：旧代次搜索批次不能覆盖新结果；连续历史请求采用 latest-wins；选择失败只校正仍匹配当前修订的页面状态。
- 入队恢复：预检和目录后处理在后台执行；任务提交只发生一次，即使目录后处理失败，任务仍立即启动并通过已有任务键恢复目录状态。

上述合同包含在 301 项聚焦回归中并全部通过；聚焦范围覆盖结果模型、内容页面、目录、内容服务、控制器、动作桥、全账号搜索端到端和打包合同。
