# v0.9.0 文件完整性与精准修复验证

## 验收范围

- v0.8.0 数据库幂等迁移与项目内数据保留。
- 全新、续传和既有文件的 SHA-256 基线。
- 缺失、大小异常、同尺寸篡改、读盘失败、取消和路径越界。
- 所选媒体冲突安全留档与精准重新下载。
- 1180×720 图形界面、控制器编排、关闭收敛与隐私日志。
- 便携包、安装包、签名双源在线更新与直启数据保留。

## 自动化与真实化验证

正式发布前从干净发布提交连续执行三轮完整测试，并使用隔离的 v0.8.0 真实数据副本执行基线、同尺寸篡改、检出和受控修复。每轮数量、耗时和副本哈希将在发布提交中记录。

## 构建与发布证据

正式产物 URL、字节数、SHA-256、标签提交、签名清单验证、GitHub / 魔搭指针与直启数据保留结果将在双源发布完成后记录；发布标签保持指向发布代码提交，发布后证据仅追加到源码分支。
