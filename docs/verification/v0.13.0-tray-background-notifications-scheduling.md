## 数据与安全边界

- 应用业务数据仍只写入应用目录；唯一可选系统集成是当前用户 Run 键中的固定 `TelegramDownloader` 值。
- 通知测试只验证固定聚合文案，不保存账号、来源、消息、搜索词、文件名或路径。
- 本记录不得加入凭据、真实账号、真实聊天、真实文件名、用户绝对路径或未脱敏日志。
